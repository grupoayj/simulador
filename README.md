# Sitio web Grupo Corporativo AYJ

Sitio estático hecho con HTML, CSS y JavaScript. No necesita instalar dependencias ni configurar un servidor.

## Abrirlo en Visual Studio Code

1. Descomprime el proyecto si lo recibiste como archivo ZIP.
2. En Visual Studio Code, selecciona **Archivo → Abrir carpeta** y elige `ayj-web`.
3. Abre `index.html` en el navegador. También puedes usar la extensión **Live Server** para previsualizarlo mientras editas.

El archivo `logo.png` debe permanecer junto a `index.html`, ya que la página lo carga mediante una ruta relativa.

## Publicarlo en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube `index.html`, `logo.png`, `.nojekyll` y `README.md` a la raíz del repositorio.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama principal (normalmente `main`) y la carpeta **/ (root)**, y guarda.
6. GitHub Pages mostrará la dirección pública del sitio en esa misma sección cuando termine el despliegue.

## Antes de publicarlo

- Confirma con AYJ la vigencia, periodicidad y alcance de las tarifas.
- Revisa que las tarifas de los cuatro paquetes correspondan exactamente a los componentes descritos (EPS, ARL, CCF y AFP).
- Completa y enlaza la política de tratamiento de datos personales antes de incorporar formularios que recojan datos personales. El orientador actual no solicita datos identificables y solo prepara el mensaje que la persona puede enviar voluntariamente por WhatsApp.
- La comparación económica es orientativa: los paquetes que no incluyen AFP no ofrecen la misma cobertura pensional que la referencia general del independiente.
